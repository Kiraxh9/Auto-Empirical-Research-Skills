# 语步标注 Kappa 一致性分析 —— 北京师范大学 F02「学院简介」

> **配对**：`Beijing Normal University.txt`（AI 嵌套标注）　vs　`27_Beijing_Normal_University_10语步标准标注全文.txt`（标准标注）
> **分析单元**：N = 17 个语段　|　**类目**：M01–M10 + OTHER（11 类）
> **生成日期**：2026-10-23　|　**编码本**：`06_中美高校外语院系_精炼10核心语步编码手册.csv`
> **可复现脚本**：`../kappa_move_agreement.py`

## 一、一句话结论

**Cohen's κ = 0.858（SE = 0.092，95% CI [0.676, 1.000]，p < .001，N = 17）**，按 Landis & Koch (1977) 属 **"几乎完美 Almost perfect"** 区间；严格一致率 88.24%（15/17），宽松一致率 94.12%（16/17）。

但请注意两点：**N = 17 只是单篇语料**；且这是 **AI 标注 vs 标准（金标准）标注** 的一致度，严格说属于"与金标准的吻合度 / 效标关联效度"，而非两名独立标注员之间的信度。正式投稿建议把全部 12 所高校合并成一个单元池后再报告 κ。详见第六节。

## 三、两条必须先定的分析口径

### 3.1 嵌套标签：为什么拿「外层」当主语步？

AI 标注文件的 17 个单元中有 **10 个是嵌套结构**（如 `<M08><M05>…</M05></M08>`），标准标注文件**全部是扁平单标签**（无内层）。必须先把内外层关系定下来才能一一对应。

判定依据来自**数据本身**，不是假设：

| 口径 | 与标准标注的命中数 | 结论 |
| :--- | :--- | :--- |
| 取 **外层** 作为主语步 | **15 / 17（88.2%）** | ✅ 外层 = 主语步，与标准标注同一层级 |
| 取 **内层** 作为主语步 | 1 / 17（5.9%） | ✗ 内层不是与标准标注对齐的层级 |
| 宽松：标准语步 ∈ {外层, 内层} | **16 / 17（94.1%）** | 内层是 AI 额外细分的**子语步（sub-step）** |

因此本数据包给出三层信息，主分析用**外层（严格口径）**：

- `RaterA_Outer`　→ 主语步 → **主分析（κ = 0.858）**
- `RaterA_Inner`　→ 子语步（10 个单元有值，7 个为空）
- `Agree_Lenient` → 宽松一致（**κ 不适用**，多标签情形只报百分比一致率 94.12%）

> 说明：多标签情形下 Cohen's κ 的"每单元恰好一个类别"前提被破坏，强行套 κ 会算错机会一致率，故**只报百分比一致率**。若审稿人要求多标签信度，建议改用 Krippendorff's α（其对多标签与缺失值均有定义）。

### 3.2 两处不一致是什么

| # | 语段 | A 外层 | A 内层 | B 标准 | 严格 | 宽松 | 性质 |
| :-- | :--- | :-- | :-- | :-- | :-- | :-- | :--- |
| 1 | *School of Foreign Languages and Literature*（标题行） | OTHER | — | M01 | ✗ | ✗ | **实质分歧**：A 把机构名称标题当成"网页残片"过滤，标准标注认定为 M01「界定机构身份」 |
| 5 | *The school hosts a CSSCI journal…* | M06 | M07 | M07 | ✗ | ✓ | **层级分歧**：A 认为外层属 M06「办学支撑条件」、内层 M07「声誉实绩」；标准标注直接判 M07 |

两处共同指向两条可写进 Master Prompt 的改进规则：

> ① 院系／机构名称标题**不得**标为 OTHER，应归 M01。（编码手册已明令"严禁将人员组成名录误标 OTHER"，此处可补充"机构名称标题同此"。）
> ② `M06 / M07` 边界（"本院主办的期刊、平台"到底算"支撑条件"还是"声誉实绩"）以**交际目的**为准：旨在**证明已兑现的声誉成果** → M07；旨在**说明可获得的资源条件** → M06。主办 CSSCI 期刊属前者。

> **OTHER 的 κ = 0 怎么解释？**
> 这不是"零信度"，而是 κ 的**结构退化**：当一方从未使用某类别时，Po 恰好等于 Pe（本例都是 .9412），分子恒为 0。正确读法是"AI 比标准标注**多标了 1 个 OTHER**"，即 OTHER 有**过度使用（over-use）**倾向——但仅 1 例，不足以定论。报告时建议写："OTHER 出现 1 例分歧（AI 多标），逐类 κ 因边际退化为 0，不予解释。"

## 五、一个必须知道的 SPSS 技术坑（已在本数据包中解决）

SPSS `CROSSTABS` 的 Kappa 有两个硬约束，本数据**两条都会踩**：

1. **表格必须是方阵**（行、列取值集合完全相同）。本例 OTHER 只被 AI 用了 1 次、标准标注从未使用 → 直接跑会报
   *"Kappa statistics cannot be computed. The table is not square."*
2. **两个变量存储类型必须一致**；若都是字符串，还要求**定义长度**相同（`"M01"` 长 3、`"OTHER"` 长 5）→ 用字符串变量几乎必然失败。

本数据包的解决办法（IBM / UCLA 统计咨询的标准做法）：

- 全部改用**数值编码**变量 `A_Code` / `B_Code` / `A_Flag_Outer` / `B_Flag`（M01=1 … M10=10, OTHER=11）；
- 在频数表中把缺失类别的**对角格** `(OTHER, OTHER)` 预置 `0.0001` 的极小权重（列 `W_forKappa`），使该行该列都出现在表中，而对结果的影响可忽略：

| | κ 值 |
| :--- | :--- |
| 未补齐（真值，Python 计算） | 0.85774059 |
| 补齐后（SPSS 将输出的值） | 0.85774171 |
| 差异 | 1.1 × 10⁻⁶（第 5 位小数起） |

因此**SPSS 跑出的 0.858 与 Python 的 0.8577 是同一个数**，可直接互校。

## 六、方法与报告建议（写给论文"信度检验"一节）

1. **口径声明**：主分析口径是"AI 嵌套标注的**主语步（外层）** vs 标准标注"；分析单位＝语段（annotation unit）；类目＝M01–M10 + OTHER 共 11 类；每个单元给出**恰好一个**主类目 —— 满足 Cohen's κ 的前提。
2. **性质声明**：对照方是**金标准（标准标注）**，因此 κ 衡量的是"AI 标注与标准的一致性"，属**效标关联效度 / 与金标准的吻合度**；若研究设计是"两名独立标注员互盲"，则直接称**评分者间信度（inter-rater reliability）**。两种写法不要混用。
3. **样本量警告**：**N = 17 太小**。κ 的抽样变异很大（95% CI 宽达 [0.68, 1.00]），M01 的边际频数只有 1–2 例，其逐类 κ = .638 极不稳定（改 1 例就会跳变）。
   → **强烈建议**：把全部 12 所高校的标注单元**合并成一个池**（预计数百单元）再报总体 κ，本例只作为"单篇试标注"或"预测试 pilot"报告。合并方法：把各篇的 `SPSS_01_主数据_每单元一行.csv` 纵向拼接后重跑 `kappa_move_agreement.py`。
4. **κ 悖论（prevalence / marginal problem）**：本例语步分布高度不均（M08 占 4/17，M03/M04/M09/M10 完全为 0），κ 对边际分布敏感。除 κ 外，建议**同时报告原始一致率（88.24%）**，并在正文交代各语步的边际频数，让读者自行判断。
5. **Bootstrap CI 更可取**：N 小，且 κ 的正态近似上界超过 1（1.039，已截为 1.000），说明正态近似在此不成立。论文中建议报 **Bootstrap 百分位 CI [0.646, 1.000]**。SPSS 的 CROSSTABS 不提供 κ 的 Bootstrap，故本数据包用 Python 直接给出。
6. **可写进正文的模板句**：
   > 以 17 个语段为分析单位，对 AI 标注与标准标注的 10 核心语步（含 OTHER）编码进行一致性检验。结果显示观察一致率为 88.24%，Cohen's κ = 0.858（SE = 0.092，95% Bootstrap CI [0.646, 1.000]，p < .001），按 Landis & Koch (1977) 属"几乎完美"水平。两处分歧分别集中于机构名称标题的 OTHER / M01 判定，以及 M06 / M07 的"支撑条件 / 声誉实绩"边界。
