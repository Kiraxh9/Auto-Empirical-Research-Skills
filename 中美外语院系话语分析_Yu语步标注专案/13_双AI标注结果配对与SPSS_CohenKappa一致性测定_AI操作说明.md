# 13｜双 AI 标注结果配对与 SPSS Cohen's Kappa 一致性测定 —— AI 操作说明

> 本说明供执行“标注结果配对”任务的 AI 阅读并严格遵循。
> 目标：将两位 AI 标注员（**Rater1**、**Rater2**）对**同一批原始 `.txt` 语料**产出的 **10 核心语步（`M01–M10` + `OTHER`）XML 标注文件**，逐行对齐、提取语步标签，生成可直接导入 **SPSS 计算 Cohen's Kappa** 的成对名义尺度数据表。
>
> 输出样式基准（用户样例 `副本test01_nominal_2_raters.csv`）：
> ```
> Line,Rater1,Rater2
> 1,M01,M01
> 2,M01+M02,M01
> 3,,
> 4,,
> ...
> ```

---

## 0. 角色与任务边界

- 你是“配对处理 AI”：**只读**输入文件、**只产出 CSV**。
- **严禁**修改、重写、合并或“修补”两位标注员的原始标注文件。
- 任何一步校验失败 → **立即停止**并在报告中说明，**不得自行猜测或修复**。

---

## 1. 输入约定

| 输入 | 命名约定 | 说明 |
| :--- | :--- | :--- |
| 原始语料 | `<高校名>.txt`（如 `Harvard University.txt`） | 未标注的干净文本，行结构基准 |
| Rater1 标注 | `RateR1_<高校名>.txt` | 与原始文件逐行对应的 10 语步 XML 标注 |
| Rater2 标注 | `RateR2_<高校名>.txt` | 与原始文件逐行对应的 10 语步 XML 标注 |

**标签体系**：`M01–M10`（核心语步）+ `OTHER`（导航/纯版头等）。
**复合标签写法**：嵌套书写 `<M05><M09>...</M09></M05>`（外层 = 主语步，内层 = 次语步），在配对表中对应字符串 `M05+M09`。

---

## 2. 处理步骤（必须逐条执行）

### 步骤 1：保真与结构校验（先做，失败即停）

对每个标注文件 `Ai`（i = 1, 2）：

1. 剥离 `Ai` 中全部 `<Mxx>`、`</Mxx>`、`<OTHER>`、`</OTHER>` 标签，得到纯文本；
2. 与原始文件**逐行、逐词比对**：必须完全一致（含空行位置、标点、大小写）；
3. 行数必须一致。

任一不满足 → 停止，报告 `文件名 + 行号 + 差异内容`。

### 步骤 2：按原始行分块

- 将两个标注文件按“物理空行”切分为块序列 `blocks_1[]`、`blocks_2[]`；
- 空块对应原始文本中的空行；
- 要求 `len(blocks_1) == len(blocks_2) == 原始行数 N`，否则停止并报告。

### 步骤 3：逐行提取语步标签（extract_label）

对每个块：

1. 按文档顺序扫描块内所有标签符号，还原标签嵌套链；
2. 将块内文本段按“独立文本段”分组，每组取其标签链（**外层 → 内层**）；
3. 每个链标签用 `+` 连接（如 `M05+M09`）；
4. 多个文本段的链标签按出现顺序合并（相同链标签去重）；
5. 无任何标签 → 返回空字符串 `""`（该行两格留空）。

伪代码：

```python
def extract_label(block: str) -> str:
    segments = split_segments_by_tags(block)   # [(text, [outer, inner, ...]), ...]
    chains = [chain_label(seg) for seg in segments if seg.tags]  # 每段取链
    seen = []
    for c in chains:
        if c not in seen:
            seen.append(c)
    return "+".join(seen)
```

**示例**：

```
原始行: The department offers courses in French and German.
Rater1: <M05>The department offers courses in French and German.</M05>
Rater2: <M05><M09>The department offers courses in French and German.</M09></M05>

CSV 行: 12,M05,M05+M09
```

### 步骤 4：生成配对 CSV

- 表头固定：`Line,Rater1,Rater2`
- `Line` = 原始文件行号，从 1 到 N，**包含空行**（行号连续）
- 每行一条记录：`<Line>,<Rater1标签>,<Rater2标签>`；标签为空时留空（如 `3,,`）
- 编码 **UTF-8（无 BOM）**，逗号分隔，**CRLF 换行**（与样例一致）
- **仅三列**，不含任何注释行、汇总行或额外列

### 步骤 5：自检清单（输出前全部通过）

1. CSV 行数 == 原始文件行数 N；
2. 每行两个标签均满足正则 `^(?:M(?:0[1-9]|10)|OTHER)(?:\+(?:M(?:0[1-9]|10)|OTHER))*$` 或为空；
3. 随机抽取 **≥ 10 行**与两个标注文件逐行人工复核，标签一致；
4. 报告：每校标签分布（Rater1/Rater2 各自 `M01–M10`、`OTHER` 计数）与行级不一致条数。

---

## 3. 输出命名与目录

| 输出 | 路径 | 表头 |
| :--- | :--- | :--- |
| 单校配对表 | `kappa_pairs/<高校名>_kappa_pairs.csv` | `Line,Rater1,Rater2` |
| 批量汇总长表（供 SPSS 分层计算） | `kappa_pairs/全部高校_kappa_pairs_long.csv` | `File,Line,Rater1,Rater2`（`File` 填高校名） |

---

## 4. 边界情形处理表

| 情形 | 处理 |
| :--- | :--- |
| 原始行是空行 | 两格留空，仍占一行（行号连续） |
| 一行内只有一个标签 | 直接记录（如 `M05`） |
| 一行内嵌套两标签 `<M05><M09>x</M09></M05>` | 记录 `M05+M09`（外层在前） |
| 一行内多个并列文本段 `<M01>a</M01><M02>b</M02>` | 记录 `M01+M02`（按出现顺序） |
| 某行 Rater1 有标签、Rater2 无标签 | 保留原样（Kappa 计为不一致），不推断 |
| 复合标签顺序（如 `M09+M05`） | 原样保留，不重排（顺序承载主/次语步信息） |
| `OTHER` 标签 | 记录为 `OTHER`，参与名义尺度比较 |
| 两个标注文件行数/保真不一致 | 停止并报告，禁止修补 |

---

## 5. 批量执行规则

- 对全部高校逐一执行步骤 1–5；
- 每个文件独立校验、独立报告；**单校失败不影响其余高校**；
- 全部完成后输出汇总表：每校一行（文件名、N、不一致行数、数据就绪状态）。

---

## 附：SPSS 操作指引（供人类使用者参考）

1. 打开 SPSS → `文件 > 导入数据 > CSV`，编码选 **UTF-8**，勾选“第一行是变量名”；
2. `分析 > 描述统计 > 交叉表`：行 = `Rater1`，列 = `Rater2`；
3. `统计(Statistics)` → 勾选 **Kappa**；`单元格(Cells)` → 勾选 **观测值**与**期望值**；
4. 解读：Kappa ≥ 0.80 几乎完全一致；0.60–0.79 实质一致；0.40–0.59 中等；< 0.40 不足；
5. 注意：Kappa 受类别分布偏倚影响，建议同时查看交叉表对角线与边缘分布；多校合并分析时可用“按 `File` 拆分”（数据 > 拆分文件）。
