# 13｜双 AI 标注结果配对 → SPSS Cohen's Kappa 数据 CSV —— AI 操作说明

> 本说明供执行“标注结果配对”任务的 AI 阅读并严格遵循。
> 场景：用户把**两组已标注文件**（分别由两位 AI 标注员 **Rater1**、**Rater2** 对同一份原始文本独立生成）发给你。你将两组文件逐行配对、提取语步标签，输出一份可直接导入 **SPSS 计算 Cohen's Kappa** 的 CSV。
>
> 输出样式基准（用户样例 `副本test01_nominal_2_raters.csv`）：
> ```
> Line,Rater1,Rater2
> 1,M01,M01
> 2,M01+M02,M01
> 3,,
> 4,,
> ...
> ```

---

## 0. 任务边界

- 你是“配对处理 AI”：**只读**输入文件、**只产出 CSV**。
- **严禁**修改、重写、合并或“修补”任何一组标注文件。
- 任何一步校验失败 → **立即停止**并在报告中说明，**不得自行猜测、强行对齐或修补**。

---

## 1. 输入约定（用户提供的两组文件）

| 组 | 归属 | 文件 |
| :--- | :--- | :--- |
| 第一组 | **Rater1** | `Rater1/<高校名>.txt`（如 `Rater1/Harvard University.txt`） |
| 第二组 | **Rater2** | `Rater2/<高校名>.txt`（如 `Rater2/Harvard University.txt`） |

**配对规则**：
- 按**完全相同的文件名**配对（`Rater1/` 与 `Rater2/` 下同名文件为一对）；
- 文件名不一致 → 报告“无法配对”，不猜测对应关系；
- 若用户直接在对话中分两组发送、未建文件夹，以用户指明的分组为准（第一组 = Rater1，第二组 = Rater2），不确定时先询问。

---

## 2. 标注标签体系（供你识别）

- `M01–M10`：10 个核心语步（`M01` 治理 / `M02` 历史 / `M03` 使命 / `M04` 研究取向 / `M05` 培养 / `M06` 师资条件 / `M07` 声誉实绩 / `M08` 合作服务 / `M09` 互动动员 / `M10` 入口规程）；
- `OTHER`：导航栏、纯版头、无实质话语功能的片段；
- **复合标签写法**：嵌套书写 `<M05><M09>文本</M09></M05>`（外层 = 主语步，内层 = 次语步），在配对 CSV 中记为字符串 `M05+M09`。

---

## 3. 处理步骤（必须逐条执行）

### 步骤 1：结构校验（先做，失败即停）

1. 将两个文件按**物理空行**切分为块序列 `blocks_1`、`blocks_2`（空块对应原文空行）；
2. 要求 `len(blocks_1) == len(blocks_2)`——**不等则停止并报告**（说明两位标注员未保持同一行结构，无法可靠配对）；
3. 对每个块：剥离标签得到纯文本，要求两文件对应块的纯文本**逐词一致**（允许标签差异，不允许文本差异）；任一不一致 → 停止并报告 `文件名 + 块号 + 差异内容`。

> ⚠️ 方法学要点：Kappa 必须建立在**完全相同的编码单元**上。若两个文件行结构不一致（哪怕一方只是把一行拆成多行、文本词序列完全相同），也必须停止报告，**不要强行对齐**。

### 步骤 2：逐块提取语步标签（extract_label）

对每个块：

1. 按文档顺序扫描块内所有标签符号，还原标签嵌套链；
2. 将块内文本段按“独立文本段”分组，每组取其标签链（**外层 → 内层**）；
3. 每个链标签用 `+` 连接（如 `M05+M09`）；
4. 多个文本段的链标签按出现顺序合并（相同链标签去重）；
5. 无任何标签 → 返回空字符串 `""`（该行两格留空）。

伪代码：

```python
def extract_label(block: str) -> str:
    segments = split_segments_by_tags(block)   # [(text, [outer, inner, ...]), ...]
    chains = [chain_label(seg) for seg in segments if seg.tags]  # 每段取链
    seen = []
    for c in chains:
        if c not in seen:
            seen.append(c)
    return "+".join(seen)
```

**示例**：

```
Rater1 块: <M05>The department offers courses in French and German.</M05>
Rater2 块: <M05><M09>The department offers courses in French and German.</M09></M05>

CSV 行: 12,M05,M05+M09
```

### 步骤 3：生成配对 CSV

- 表头固定：`Line,Rater1,Rater2`
- `Line` = 块序号，从 1 到 N，**包含空块**（行号连续）
- 每行一条记录：`<Line>,<Rater1标签>,<Rater2标签>`；标签为空时留空（如 `3,,`）
- 编码 **UTF-8（无 BOM）**，逗号分隔，**CRLF 换行**（与样例一致）
- **仅三列**，不含任何注释行、汇总行或额外列

### 步骤 4：自检清单（输出前全部通过）

1. CSV 行数 == 块数 N；
2. 每行两个标签均满足正则 `^(?:M(?:0[1-9]|10)|OTHER)(?:\+(?:M(?:0[1-9]|10)|OTHER))*$` 或为空；
3. 随机抽取 **≥ 10 行**与两个文件的对应块逐块复核，标签一致；
4. 报告：每校标签分布（Rater1/Rater2 各自 `M01–M10`、`OTHER` 计数）与行级不一致条数。

---

## 4. 输出命名与目录

| 输出 | 路径 | 表头 |
| :--- | :--- | :--- |
| 单校配对表（每对文件一份） | `kappa_pairs/<高校名>_kappa.csv` | `Line,Rater1,Rater2` |
| 批量汇总长表（多校时生成） | `kappa_pairs/全部高校_kappa_long.csv` | `File,Line,Rater1,Rater2`（`File` 填高校名） |

---

## 5. 边界情形处理表

| 情形 | 处理 |
| :--- | :--- |
| 块是空行（原文空行） | 两格留空，仍占一行（行号连续） |
| 块内只有一个标签 | 直接记录（如 `M05`） |
| 块内嵌套两标签 `<M05><M09>x</M09></M05>` | 记录 `M05+M09`（外层在前） |
| 块内多个并列文本段 `<M01>a</M01><M02>b</M02>` | 记录 `M01+M02`（按出现顺序） |
| 某块 Rater1 有标签、Rater2 无标签 | 保留原样（Kappa 计为不一致），不推断 |
| 复合标签顺序（如 `M09+M05`） | 原样保留，不重排（顺序承载主/次语步信息） |
| `OTHER` 标签 | 记录为 `OTHER`，参与名义尺度比较 |
| 两文件行结构/块数不一致 | 停止并报告，禁止强行对齐或修补 |
| 两文件对应块纯文本不一致 | 停止并报告，禁止强行对齐或修补 |
| 文件名无法配对 | 报告无法配对，不猜测对应关系 |

---

## 6. 批量执行规则

- 对每所高校（每对同名文件）逐一执行步骤 1–5；
- 每个文件独立校验、独立报告；**单校失败不影响其余高校**；
- 全部完成后输出汇总表：每校一行（文件名、N、不一致行数、数据就绪状态）。

---

## 附：SPSS 操作指引（供人类使用者参考）

1. 打开 SPSS → `文件 > 导入数据 > CSV`，编码选 **UTF-8**，勾选“第一行是变量名”；
2. `分析 > 描述统计 > 交叉表`：行 = `Rater1`，列 = `Rater2`；
3. `统计(Statistics)` → 勾选 **Kappa**；`单元格(Cells)` → 勾选 **观测值**与**期望值**；
4. 解读：Kappa ≥ 0.80 几乎完全一致；0.60–0.79 实质一致；0.40–0.59 中等；< 0.40 不足；
5. 注意：Kappa 受类别分布偏倚影响，建议同时查看交叉表对角线与边缘分布；多校合并分析时可用“数据 > 拆分文件”按 `File` 分层计算。
