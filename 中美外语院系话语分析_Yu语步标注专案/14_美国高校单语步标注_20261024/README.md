# 14｜美国高校外语/区域研究院系 10 核心语步标注（2026-10-24）

沿用 `13_单语步优先重标_20261024/` 的**单语步优先**口径（每单元只给 1 个主导语步，零复合标签），对用户新提供的 **10 所美国高校** 院系页面文本做 `M01–M10 + <OTHER>` 标注。

> **重要说明（请先读）**：本批 10 校共 **9,691 个标注单元 / 129,000+ 词**，规模是上一批（891 单元）的 **10.9 倍**，无法逐句人工判读。因此本批采用 **规则辅助初标（`auto_label.py`）+ 人工抽样审核 + 低置信度复核清单** 的流水线，属**机器初标版（AI first-pass）**，与 13 号文件夹的逐句人工判定版在证据等级上不同。使用前请按下文"五、质量状况"读一遍。

## 二、切分口径

| 规则 | 说明 |
| :--- | :--- |
| 一句一单元 | 完整句 = 单元，标签只在首尾，不切到短语层 |
| 名片/地址块整体封装 | 含 `Tel / Email / Address / Postcode` 的人员卡片、地址块作为 **一个 `<M10>` 单元** |
| 项目符号块整体封装 | 院系列表、课程模块、社团清单不拆散 |
| 缩写例外 | `U.S. / Ph.D. / e.g.` 不误切；`etc.` 后接大写视为句末 |

> 美国院系页面大量是名录/课表/年份碎片（本批 9,691 单元中 **51.7% ≤8 词**，**78.6% 无谓语**），这是切分后单元数偏高的原因，也决定了下文的质量水平。

## 三、规则辅助标注器的判定顺序（`auto_label.py`）

1. **A 非命题残片 → `<OTHER>`**：孤立菜单/栏目名、年份碎片、`Read more / Download` 之类。
2. **B 联系方式 / 地址块 → `<M10>`**：邮箱、电话、`Mailing Address`、含邮编街道地址。
3. **C 人员名录 → `<M01>`**：纯人名（含"姓, 名"）、人名+职务、无句末标点的职务行、竖线名片（无邮箱电话时）。
4. **D 强特征短语**：`our mission / land acknowledgment → M03`；`founded in / renamed / in memoriam → M02`；`make a gift / we invite → M09`；`office hours / deadline / RSVP → M10`；`Research Interests: → M04`；`Support the Department → M09`；招聘与申请句 → `M10`；`Learn more/visit our page → M09`。
5. **E 加权线索打分**（10 类语步各一组正则线索）+ **并列裁序** `M05>M06>M07>M02>M08>M01>M10>M03>M09>M04`。
6. **F 弱兜底与上下文继承**：打分极弱者沿用上文语步（连续 ≤2 句、且上文非 `<M01>`），模拟"段落内语步同质"的体裁事实。
7. 判定路径写入 `labels/*.paths.tsv`（`det / strong / score / fallback`），供质控与复核使用。

## 五、质量状况（务必按此使用）

**抽样人工审核**：对 ≥8 词的实质句随机抽 60 条逐条判读，**正确约 43/60（≈72%）**，错误集中在：

| 常见错误 | 例 | 说明 |
| :--- | :--- | :--- |
| 历史叙事被判为其他语步 | "Hightower inaugurates a second course…" 被判 `M05` | 应为 `M02`（事件史） |
| 招聘/申请句被判 `M04/M05` | "The successful candidate will teach…" | 应为 `M10` |
| 事件报道被判 `M10` | "In a formal gathering on the sidelines of the UN…" | 应为 `M10-S3` 可接受，或 `M08` |
| 长职称串被判 `M01` | "Kralik and Yunli Lou Professor of…" | 名录页可接受，正文段落则为噪声 |
| 政策/合规句被判 `M04` | "By accessing this website…" | 应为 `OTHER/M10` |
| 纪念/悼念句 | "Professor Wiesel passed away…" | 判 `M02` 正确，但常与 `M07` 混淆 |

**因此建议**：
1. **做分布对比前**，先用 `标注结果/02_低置信度复核清单.csv`（1,860 条，判定路径为 fallback 且 ≥7 词的实质句）做一轮人工修订；
2. 修订写入 `脚本与质检/overrides.tsv`（`校名<TAB>单元号<TAB>语步`），重跑 `auto_label.py` 即覆盖，无需手改正文；
3. 若需要研究级精度，建议只挑 3–5 所核心对比校做全量人工复核（我可按校逐句重标，单校 300–600 单元可控）。
