# 中美高校外语院系话语分析 —— Yu (2023) & Yu et al. (2026) 标准语步标注专案

本专案围绕《中美高校外语院系“学院简介”文本的话语建构与比较研究》（`RQ1–RQ5`），建立 **10 核心语步（`M01–M10` + `<OTHER>`）标准编码体系**，并按国家分设 **[`中国大学/`](./中国大学)** 与 **[`美国大学/`](./美国大学)** 两个语料标注文件夹（全部文本均经自动化脚本核验：**`100.00%` 原文逐词逐符号零删改保真 + `100%` 合法 XML 语法树**）。

### 附：语步标注信度检验（编号 12）

`12_语步标注信度检验_Kappa/` 提供「两份标注文件 → Kappa 一致性 → SPSS 可直接分析的数据表」的完整流水线：

| 内容 | 说明 |
| :--- | :--- |
| [`kappa_move_agreement.py`](./12_语步标注信度检验_Kappa/kappa_move_agreement.py) | 解析 `<M08><M05>…</M05></M08>` 嵌套标签，按语段文本自动对齐，输出整体 κ（含 FCE 标准误、正态 CI、Bootstrap CI）、逐语步 κ、加权 κ、混淆矩阵 |
| [`BNU_AIvs标准/`](./12_语步标注信度检验_Kappa/BNU_AIvs标准) | 首批实例：**北京师范大学 F02**（`N = 17` 单元）—— `κ = 0.858`、`Po = 88.24%`、宽松一致率 `94.12%` |

> **口径要点**：AI 嵌套标注以**外层为主语步**、内层为子语步（数据验证：外层与标准标注命中 15/17，内层仅 1/17）；多标签的宽松口径**不适用 κ**，只报百分比一致率。SPSS `CROSSTABS` 的 Kappa 要求表格为方阵且两变量类型一致，数据包已用数值编码 + 对角格 `0.0001` 补权重预处理（κ 影响 < 1e-5）。
