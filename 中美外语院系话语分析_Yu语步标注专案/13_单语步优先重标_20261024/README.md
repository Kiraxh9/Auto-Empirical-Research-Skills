# 13｜10 核心语步「单语步优先」重标（2026-10-24）

本文件夹按 `07_AI语步标注操作说明_10核心语步标准版.md` 与 `06_中美高校外语院系_精炼10核心语步编码手册.csv` 的正式标准，对 **10 所中国高校外语院系英文简介** 语料重新做了一次 **`M01–M10 + <OTHER>` 语步标注**。

**本次标注的核心要求：尽量不标复合语步。** 每个标注单元只赋 **1 个主导语步**，全部 891 个单元 **零复合标签（单语步率 100%）**。

## 二、切分规则（"少标复合语步"的第一道保障）

| 规则 | 说明 |
| :--- | :--- |
| **一句一单元** | 一个完整句 = 一个标注单元；标签只加在句首与句末，绝不切分到短语/小句层。 |
| **名片整块为一单元** | 含 `Tel / Email / Address / Postcode` 等联系字段的人员卡片、地址块（如 DUT、HIT、ECNU 的领导与行政名录）**整体封装为一个 `<M10>` 单元**，避免把一张名片拆成 4–5 个行级单元稀释词频。 |
| **名录块整块为一单元** | 无联系方式的职务/师资名录（如 `Full Professor: … / Associate professor: …`、`Professors: … / Instructors: …`）整体封装为 `<M01>`；项目符号列表（院系列表、课程模块、社团清单）同理不拆散。 |
| **不跨句合并** | 除上述两种"内聚名录块"外，不做任何句子合并，因此不会人为制造复合语步。 |
| **段落空行保留** | 输出保留原网页的段落分行，便于逐段核对。 |
| **缩写例外处理** | `U.S. / Ph.D. / e.g.` 等缩写不误切；但 `etc.` 后接大写视为句末正常切分。 |

## 三、单语步判定顺序（多义句的处置规则）

一个句子涉及两种以上交际目的时，只保留 **1 个真正主导的语步**，按以下优先级裁决：

1. **看谓语与主句命题**，而不看修饰成分。例：`Founded in 1932, FLC has now grown into one of the largest schools…` → 主句是创办时间 → `<M02>`（"one of the largest"只是附加评价，不升级为 M07）。
2. **看句子在语篇中的功能位置**（章节标题下的首句往往承担该章节功能）。例：`Strong teaching staff.` 位于师资段 → `<M06>`；`Integrated development of disciplines.` 引出系所构成 → `<M01>`。
3. **人事 vs 联系 vs 师资统计** 三分法（编码手册硬判据）：
   - 无联系方式的领导/师资/学生**名录与职务分工** → `<M01>`；
   - 带邮箱/电话/办公室/档案入口的人员卡片 → `<M10>`；
   - 正文中概括的师资**人数、职称结构、师生比** → `<M06>`。
4. **历史 vs 当下成就**：带年份的创办/合并/更名/批准授权节点 → `<M02>`；已兑现的排名、获奖、项目数、就业率 → `<M07>`。历史段落中散见的"当年即获某某称号"仍按讲述史实归 `<M02>`。
5. **在校培养 vs 毕业去向**：培养目标、课程模块、教学法、在校能力 → `<M05>`；毕业去向、升学率、就业率、校友成就 → `<M07>`；学分/考试/年限等硬性要求 → `<M10>`。
6. **研究领域列表必归 `<M04>`**：`Faculty by Area of Study`、`research directions are as follows…`、`Research fields include…` 一律 `<M04>`，不得误标 `<OTHER>` 或 `<M06>`。
7. **`<OTHER>` 只用网页噪音**：孤立菜单/页眉（`Overview / History / Faculty / Laboratories / Department of English` 等裸标题）、`Authored by …` 采集注记、重复页脚与网址之外的导航残片。**凡构成命题的真实句子一律归 M01–M10**（本次 OTHER 仅占 2.6%词）。

## 六、与既有 `中国大学/` 标注的差异说明

`中国大学/` 目录下 9 份同名文件为**早期双标签（嵌套复合）版**，本次为**单语步重标版**，两者可直接用于：
1. **复合语步 → 单语步的口径敏感性检验**（同一批文本、同一手册、不同标注策略）；
2. **与 `12_语步标注信度检验_Kappa/` 的信度分析**：新标注与旧标注按"外层主标签"对齐后计算 Cohen's Kappa；
3. **直接进入统计**：本次单语步率 100%，不再需要"外层为主、内层为子"的折算步骤，`M01–M10` 的词占比可直接作为研究变量。

> 注意：本次切分把联系名片/名录整块封装，单元数（891）与旧版（按句切分）不同；**跨版本比较请用词占比而非单元频次**。
