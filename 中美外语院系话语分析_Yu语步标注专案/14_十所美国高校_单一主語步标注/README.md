## 二、标注口径（与 13 批一致）

| 规则 | 说明 |
| :--- | :--- |
| **U1 一完整句一单元** | 以 `. ? !` 结尾的完整句，不切分词/短语/从句 |
| **U2 整体块一单元** | 地址/电话块、人物名录与教职工卡、课程清单、奖项清单 → 连同栏目标题整体封装 |
| **U3 纯结构残片** | 孤立栏目标题、页脚重复行、日期残片、乱码 → `<OTHER>` |
| **U4 原文零改写** | 拼写、`&`、`|`、乱码一律逐字符保留 |

语步核心判据仍按 `06` 手册：`M01` 身份/人员/治理；`M02` 历史与纪念；`M03` 使命愿景；`M04` 学科价值与研究取向；`M05` 学位/课程/培养；`M06` 师资与支撑条件；`M07` 声誉与毕业出路；`M08` 合作与社会服务；`M09` 欢迎与募捐动员；`M10` 联系方式/规程/通告；`<OTHER>` 纯网页残片。

## 三、为什么这批是「预标注」：规模与质量诊断

1. **规模**：本批 `131,805` 词，是中文批（`18,595` 词）的 **7.1 倍**；单元数 `7,602`，且为**整站抓取**（含多个系所、图书馆、研究生院、活动页、医学院人员页等），单校可达 3,000 单元（Harvard）。
2. **方法**：先按 `segment.py` 做保真切分，再用 `rules.py`（约 90 条判据 + 级联优先序）给每个单元唯一語步，并按规则强度输出置信度（2/1/0）。
3. **实测一致率**（人工金标）：

| 数据集 | N | 整体一致率 |
| :--- | ---: | ---: |
| 开发集（规则迭代用） | 109 | `80.7%` |
| **留出集（未参与调参）** | **60** | **`43.3%`** |
| 留出集 · 高置信单元（conf=2） | 17 | `76.5%` |
| 留出集 · 中置信单元（conf=1） | 23 | `34.8%` |
| 留出集 · 低置信单元（conf=0） | 20 | `25.0%` |

4. **结论**：规则法在**强信号**单元上可靠（邮箱/电话/地址块、人物卡、募捐与欢迎语、`1936 / …` 纪年条目 → 一致率 ≥ 90%），
   但在**需要语境推理**的三类边界上明显不足：`M04` 研究取向 ↔ `M05` 培养体系 ↔ `M07` 声誉实绩。
   因此**不宜**用这批机器结果直接做中美对比统计。

## 四、复核指引（若选择「保留全量 + 人工复核」路线）

1. 打开 `待复核清单_中低置信度.csv`（`4,206` 单元），按 `判定依据` 列排序，同类型批量处理：
   - `fallback`（低置信兜底）：优先复核，占错误的大头；
   - `degree` / `research` / `resource` / `prestige`：这四类判据相互竞争，需按手册边界逐条定夺；
   - `person-card` / `contact` / `donate` / `timeline`：一般可直接采纳。
2. 修改方式：直接改 `标注后语料/*.txt` 的行首行尾标签，再跑 `python3 scripts/validate.py` 与 `build.py` 重算统计。
3. 建议抽样复核 10%（约 760 单元）估计残余错误率，报告为「人工复核后一致率」。
