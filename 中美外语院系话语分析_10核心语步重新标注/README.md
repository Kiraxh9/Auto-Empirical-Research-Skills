## 二、质控核验指标（100% 自动化通过）

1. **原文逐词逐标点保真度**：`100.00%`（去除 XML 语步标签后，与上传的 preprocessed 原始 `.txt` 逐词、逐字符、逐标点符号 `100%` 严丝合缝，零删改、零增补、零改写）。
2. **XML 语法规范与单行完整单元**：`100.00%` 合法闭合标签（仅使用 `<M01>`–`<M10>` 单标签、共现双语步嵌套 `<MXX><MYY>...</MYY></MXX>`［外层为主语步、内层为次语步］及纯网页导航噪音过滤标签 `<OTHER>`），每行一个完整句或内聚名录/课程模块/联系卡片块，`100%` 兼容 `kappa_move_agreement.py` 信度检验解析器（零跳过行、零丢词）。
3. **关键排他边界严格执行**：
   - 无邮箱/电话的院系领导、师资组成名录块连同栏目标题整体封装为 `<M01>`（绝不拆为单行裸姓名，绝不误入 `<OTHER>`）；
   - 附带邮箱/电话/办公地址的联系人卡片及联系入口统一归入 `<M10>`；
   - 研究领域与学术方向列表统一归入 `<M04>`；
   - 课程模块清单连同模块标题整体封装为 `<M05>`；
   - `<OTHER>` 严格仅用于剥离无命题孤立栏目标题（全库平均有效词保留率达 **`98.55%`**）。
