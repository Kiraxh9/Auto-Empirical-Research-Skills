## 一、标注方法与可信度披露

本批次规模为上一批（`BU` + `DUT`，约 `1.4` 万词）的 **8.4 倍**，因此采用**「规则—语境双引擎 + 人工金标准校准」**的 AI 辅助标注流程（`AI-assisted move annotation`，与 Yu et al., 2026 的少样本 AI 标注思路一致，但以可复现脚本替代逐句对话式投喂）：

| 环节 | 说明 |
| :--- | :--- |
| **① 单元切分** | 以「段落 → 完整句」为切分单位；句号后若遇缩写（`Ph.D. / B.S. / U.S.`）、小数、电话号码、方括号引注则不切分；多行名册/地址块整体封装为一个单元。 |
| **② 结构识别** | 先识别四类高确定性结构区：**人员名册区**（含栏目标题的 `Faculty / Administration / Emeriti / Doctoral Students` 区块）、**联系访问区**（地址、电话、办公时间、无障碍、交通）、**捐赠动员区**（`Giving / Give Today / Your gift…`）、**活动资讯区**（`Events / News / Calendar`）。名册区按「栏目标题 + 成员条目」逐条标注（带邮箱即 `<M10>`，无联系方式即 `<M01>`）。 |
| **③ 命题判分** | 对其余完整句，用语步专属线索词表加权打分（每语步 `5–8` 组正则，含排他性加权：`rank/No./QS` → `M07`；`founded/renamed/predecessor` → `M02`；`mission/committed to/DEI` → `M03`；`areas of study/research fields` → `M04`；`offers MA/PhD/courses` → `M05`；`faculty size/ratio/collections` → `M06`；`partners/study abroad/outreach` → `M08`；`welcome/join/gift` → `M09`；`email/phone/hours/deadline` → `M10`）。 |
| **④ 语境回填** | 当单句线索总分 `< 2.0`（弱命题）时，按最近的章节标题语义回填（`Mission/Vision` → `M03`；`History/Legacy` → `M02`；`Programs/Curriculum` → `M05`；`Faculty/People` → `M01`；`Contact/Visit` → `M10`；`Giving` → `M09`），以复现人工作者对「章节主导语步」的判定。 |
| **⑤ 校准与质检** | 以项目内**人工金标准** [`08_Carnegie_Mellon_University_10语步标准试标注全文.txt`](../中美外语院系话语分析_Yu语步标注专案/08_Carnegie_Mellon_University_10语步标准试标注全文.txt) 为标尺，在 `CMU`（`262` 个可比单元）上逐单元比对：**主码一致率 `71.8%`**（含双码单元的主码判定）。 |

> **可信度边界（务必写入论文方法说明）**：结构性语步（`M01` 名册、`M10` 联系与规程、`M09` 募捐与邀请、`M05` 项目课程、`M02` 建系年表）判别可靠；**细粒度区分（`M04` 学理辩护 vs `M05` 培养目标、`M06` 投入资源 vs `M07` 已兑现声誉、人物传记中的 `M02` vs `M07`）仍存在约 `1/4` 的判读分歧**，属人工作者本身亦难完全一致的边界区。若用于正式发表，建议对该四类边界做 `10–15%` 随机抽样人工复核并报告 `Krippendorff's α`。

- 本次 `CMU` 样本未重跑脚本，直接沿用项目既有**人工金标准** `08`（重命名为 `23_Carnegie_Mellon_University_10语步标准标注全文（金标准）.txt` 归档），以保证该样本零误差。

## 五、本批次浮现的三个新发现

1. **`M02` 是美国样本的第一大语步（合并 `17.18%`，Cornell `23.86%`、Harvard `23.62%`）**，但其内部构成与中文样本的「建系年表」不同：美国样本的 `M02-S3`（人物纪念、学脉致敬、讲座设立缘起、机构撤并归档）占比极高（Harvard 的 Du Bois 生平、Cornell 的建系年表、Brown 的 1764 年创系叙事）。这提示 `M02` 需按 **`S1/S2` 建制型 vs `S3` 纪念型** 二分后再比较，否则会误判「美国高校更重历史」。
2. **`M09` 并非美国样本的稳定特征（合并 `2.67%`，Georgia Tech `11.89%` vs Johns Hopkins `0%`）**：`M09` 的密度取决于页面是否嵌入**「Giving 模块」与「Visit/Apply 模块」**，而非国别本身。上一批 `BU`（`9.34%`）与 `CMU`（`7.70%`）之所以高，源于其院系页内置了完整募捐区。**建议在 `RQ3` 中把 `M09` 进一步拆为 `S3 募捐` 与 `S1/S2 欢迎与邀请` 分别检验**，避免以整体占比过度概括「市场化文体」。
3. **`M10` 已成为美国院系页的第二大语步（合并 `14.63%`，Brown `36.50%`）**：新增内容以「办公时间＋无障碍通道＋地铁公交＋停车指引＋分流咨询邮箱」为主，属典型**服务型网站（service-oriented genre）**特征；中文样本的 `M10` 仍集中于「领导班子电话邮箱名册」。这是中美体裁差异中最稳健、最易复现的一项。
