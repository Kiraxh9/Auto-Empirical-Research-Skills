# 外语院系英文About Us文本的10核心语步四方面描述框架

| 语步（Move） | 内容（Content） | 交际目的（Communicative purpose） | 体裁功能（Genre function） | 主要语阶（Main steps） |
|---|---|---|---|---|
| M01 界定机构身份、人员组成与组织治理 | 院系的机构性质、校区与上级学院隶属、独特定位，下属系科与研究中心，以及领导、行政人员、师资和学生组成。 | 说明“我们是谁、隶属哪里、由哪些人员和组织构成”，呈现院系当前的组织形态与治理结构。 | 为全篇确立机构主体，提供理解其他学术、教学与社会活动信息的组织背景。 | S1 说明机构性质、隶属与定位；S2 呈现下属系科和研究中心；S3 展示组织治理及人员组成。 |
| M02 追溯历史沿革与学脉敬意 | 院系的创办年份、前身机构、合并更名、迁址复建等历史节点，以及对先贤和已故学者的纪念与学术致敬。 | 建立院系的历史连续性，维系集体记忆，并通过学术传统与人物贡献说明其历史传承。 | 为机构身份提供时间纵深，构成连接过去与现在的历史合法性叙事。 | S1 追溯创办起源与前身；S2 叙述合并、更名等转型节点；S3 纪念人物并彰显学脉传承。 |
| M03 宣示使命愿景与公共价值立场 | 院系的根本使命、学术伦理、多元包容或国家战略担当，未来建设规划，以及对公共议题和历史责任的立场。 | 公开说明院系为何存在、坚持何种价值、承担何种公共责任，并宣示未来发展方向。 | 为全篇确立价值基调和战略方向，将院系建构为具有使命意识与公共责任的行动主体。 | S1 宣示使命、价值与责任；S2 提出战略愿景和建设计划；S3 回应公共议题并表明道义立场。 |
| M04 阐释学科价值与学术研究取向 | 语言、文学、文化及区域研究的当代价值，学科核心概念与分析方法，以及院系的研究领域、理论视角和跨学科研究集群。 | 论证相关学科与学习活动的必要性，界定院系的知识生产方式、研究范围和学术取向。 | 为院系的学术活动提供知识与研究层面的合法性说明，塑造其学科形象与学术身份。 | S1 论证学科及学习价值；S2 展示研究领域、方法和跨学科方向；S3 阐释核心概念、方法或学术论点。 |
| M05 介绍课程供给与教学培养体系 | 本硕博学位项目、主辅修与证书项目、授课语种和课程模块，以及教学方式、学习体验和学生能力培养目标。 | 说明学生“可以学什么、如何学习以及能够形成哪些能力”，呈现院系的教育供给与育人过程。 | 将机构使命落实到课程、教学和学习者培养，突出院系作为教育主体的功能。 | S1 介绍学位项目、课程和语种供给；S2 展示教学方式与学习体验；S3 阐明学生能力与素养目标。 |
| M06 展示师资力量与办学支撑条件 | 师资规模、学历职称结构与指导力量，图书文献、实验室和数字设施，以及奖助学金、科研支持和学生服务。 | 证明院系具备开展教学科研和培养学习者所需的人力、物力、财力与服务保障。 | 为教学科研承诺提供资源与条件支撑，增强院系自我呈现的可信度和吸引力。 | S1 展示师资规模与结构；S2 介绍馆藏、实验室和数字设施；S3 说明奖助机会与支持服务。 |
| M07 证明办学声誉与育人发展成效 | 学科排名、评估认证和重点资质，科研成果与师生获奖，以及毕业生升学就业、职业发展和杰出校友成就。 | 通过已经取得的成果和外部认可，证明院系的学术声誉、办学成效及其对学生发展的价值。 | 为院系的自我评价提供成果与外部认可证据，同时强化学术声望和教育回报。 | S1 展示排名、认证与资质；S2 呈现科研产出、奖项和声誉；S3 说明毕业去向与校友发展。 |
| M08 展示合作网络与社会公共服务 | 校际、跨院系、国际及政企合作，学生留学交换、联合培养和访学项目，以及咨政培训、语言测试与文化传播服务。 | 展示院系如何建立国内外合作关系，并通过专业知识开展社会服务和公共贡献。 | 将机构形象由校园内部延伸至国际合作和公共服务网络，突出其开放性与社会参与。 | S1 展示合作与学术联盟；S2 介绍交换、联合培养和访学；S3 呈现社会培训、咨政与文化服务。 |
| M09 欢迎受众、引导行动与动员支持 | 欢迎与祝愿、共同体归属表达，邀请读者浏览、参访、申请或订阅，以及捐赠倡议、基金用途说明和致谢。 | 直接面向读者建立关系，缩短机构与受众的距离，并促使其进一步参与、申请、互动或提供支持。 | 建立机构—读者之间的人际联系，将信息阅读转化为浏览、申请、参与或支持等行动。 | S1 表达欢迎与共同体归属；S2 邀请浏览、参访、申请或订阅；S3 动员捐赠并说明用途、表达感谢。 |
| M10 提供信息入口、办事规程与运行通告 | 联系方式、地址和访问入口，招生、学分、申请等规则程序，讲座会议与院系动态，以及权责和授权边界。 | 帮助读者获取信息、办理事务和了解院系运行，明确相关要求、流程与权责范围。 | 保障网站的信息导引和院系事务运行，为读者查询、申请、联系和参与活动提供实用支持。 | S1 提供联系与访问入口；S2 规定资格、要求和办事程序；S3 发布活动与运行通告；S4 说明权责和授权边界。 |
| OTHER 非命题网页残片与纯名录过滤项（非语步） | 仅包括孤立菜单或空节标题、重复页脚导航、乱码、采集备注及无关第三方自述等不构成独立交际命题的内容。 | 标记需要与有效语步文本区分开的网页残余信息，不承担独立的机构自我呈现目的。 | 作为质控类别保留网页边界信息，不参与M01—M10的语步分布统计。 | O1 孤立导航与空标题；O2 重复页脚菜单；O3 乱码、采集备注和无关第三方文本。 |

注：本表参照Yu的四方面描述思路，根据本项目《精炼10核心语步编码手册》整理。OTHER为质控类别，不计入10核心语步。
