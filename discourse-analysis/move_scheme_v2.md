# 精简版语步方案（v2）：大学外语院系 About Us 文本

> 目标：在保留研究分析价值的前提下，将原 19 Moves + OTHER 精简为 **13 Moves + OTHER**，降低 LLM 与人工标注负担。  
> 适用文本：中国与美国大学外语院系（School/Department of Foreign/Modern/World Languages 等）官方网站 About Us / 简介页面。  
> 标注粒度：**句子级**（sentence-level），与 Yu (2023) 一致。

## 一、精简对照表（原 M01–M19 → 新 M01–M13）

**精简效果**：19 → 13（减少 32%），combined moves 仍允许（如 `<M05><M06>`）。

## 二、各 Move 定义与边界准则

### M01 机构定位与组织架构
- **核心问题**：这个院系现在是什么、隶属哪个学院/校区、内设哪些子单位/中心、谁担任领导/治理角色？
- 包含：机构性质、学院/校区归属、内设系所/研究中心（仅名称）、领导职务（院长/系主任/执行委员会）、治理职责、院长/系主任致辞末尾的签名块（姓名 + 职务，作为一整块）。
- 边界：师资规模/学位比例/设施 = M07；仅列中心名称 = M01（解释研究问题 = M06）；历史沿革 = M02；排名/荣誉 = M08；裸导航/孤立标题 = OTHER。

### M02 历史沿革与学脉传承
- **核心问题**：机构从何而来、如何演变至今？
- 包含：建系年份、前身单位、合并/搬迁/更名/重建、历史里程碑（含按时间线叙述的学位项目开设年份）、创始人物。
- 边界：按时间线叙述的过去 = M02；描述当前开设的学位/课程 = M04；讣告 = M13；对历史种族主义/土地承认的道德谴责 = M03。

### M03 价值准则、学科内涵与社会服务
- **核心问题**：机构坚持什么哲学/学术价值观/民族-人文使命/公共伦理立场？学科为何重要？机构如何服务社会？
- 包含：院训/哲学、学术自由/诚信、民族服务/人类文明/DEI 承诺、公开伦理声明；学科的一般性定义与"语言/文学/文化学习为何重要"的论证；面向政府/K-12/产业/社区/公众的文化传播与服务。
- 边界：抽象的机构 ethos/价值观 = M03；学生在读期间获得的能力 = M05；课程列表 = M04；未来战略 = M11；"社会服务"若仅出现在使命口号中 = M03。

### M04 学位项目与课程供给
- **核心问题**：当前向学习者提供哪些学位、专业/辅修、证书、语种与课程？
- 包含：BA/MA/PhD/博士后项目、专业、辅修、联合专业、证书、所授语种、课程层级与具体课程名称/主题。
- 边界：客观的学位/课程清单 = M04；教学方法与学生能力培养 = M05；学分/绩点/行政程序 = M13；面向政府/公众的外部培训/测试 = M03；学生名册 = OTHER。

### M05 育人目标与教学模式
- **核心问题**：院系培养什么样的人才/能力，通过何种教学/学习实践？
- 包含：目标学生能力（批判性思维、跨文化能力、沟通能力、跨学科/创新素养）、课堂教法（小班研讨、以学生为中心的探究、导师制）、体验式/课外学习（如本科生编辑的文学期刊、读书小组）、毕业前的跨学科经历。
- 边界：毕业前的在读发展 = M05；毕业后的职业领域、就业率、读研去向、校友经历 = M10。

### M06 研究议程与学术专长
- **核心问题**：本院系及其教师积极研究哪些学术领域、历史时期、地区、理论问题与跨学科集群？
- 包含：研究专长、理论/方法论取向、明确属于本院系学者的跨学科研究集群。
- 边界：必须描述本院系的研究议程！外部图书馆/联盟范围 = M07；发表/基金数量或奖项 = M08；仅列中心名称 = M01。

### M07 师资力量与支撑资源
- **核心问题**：哪些人力、物质、档案、资金与学生支持资源支撑学习与研究？
- 包含：师资规模、职称结构、博士比例、访问/外籍/教学教师团队、师生比、图书馆、档案馆藏、语言/VR/口译实验室、常规奖学金/助学金/旅费资助/学费减免、学术/学业支持服务。
- 边界：投入条件与可用支持/资助 = M07；所获 prestigious 奖项、排名、重点学科称号、研究产出数量 = M08；强制性规章/截止日期 = M13；向校友/捐赠者募款 = M13。

### M08 学术声誉与办学成就
- **核心问题**：哪些外部排名、官方认证、累积产出、奖项或里程碑证明卓越？
- 包含：QS/国内排名、国家一流/重点学科地位、累积基金/著作/论文成就、师生荣誉与奖项（如 Pulitzer、Phi Beta Kappa、获奖教师）、学生课程评价赞誉、全国首创、累积的大型会议主办总结；具体 dated 新闻/奖项/任命/出版也可归入（以"是否有具体日期/命名事件"区分叙述粒度，但同属 M08）。
- 边界：无日期的累积会议/成就总结 = M08；未来愿景 = M11。

### M09 合作网络与国际交流
- **核心问题**：院系与哪些国内外大学、学术联盟或伙伴机构建立了合作网络或交流渠道？
- 包含：校际协议、国际学术联盟成员资格、互惠协议、留学/交换/2+2 联合项目、访问学者交流网络。
- 边界：机构合作与留学/交换渠道 = M09；学生在校园课程中获得跨文化技能 = M05；单向的面向社会/政府的公共服务/培训 = M03。

### M10 毕业出路与校友发展
- **核心问题**：毕业生去向、职业发展、校友终身收获？
- 包含：毕业后的职业领域/行业（包括"prepare students for careers in..."与"graduates have become..."）、就业/深造率、校友网络规模、具名校友职业故事或感言。

### M11 未来愿景与建设规划
- **核心问题**：展望未来，机构承诺哪些愿景、战略目标或发展举措？
- 包含：具有明确未来取向的机构承诺与战略规划（"Looking ahead...", "will continue to build...", "aim to ensure that X continues to be..."）。
- 边界：需要机构主体 + 未来取向；"look forward to welcoming you" = M12。

### M12 读者互动与联系信息
- **核心问题**：文本如何直接问候读者或邀请探索/申请/联系？在哪里可以找到地址/电话/邮箱/办公时间/联系人？
- 包含：直接问候/欢迎标题（"A Warm Welcome from...", "Welcome to...!"）、温暖的结语祝愿、明确的读者导向行动提示（"We warmly invite you to explore...", "Learn more about...", "Please don't hesitate to get in touch..."、分步"Explore / Contact / Apply"提示）；办公室位置、街道地址、房间号、办公时间、电话/传真、邮箱、联系人卡片。
- 边界：募款呼吁 = M13；裸"Contact Us"标题 = OTHER；抓取子页面重复的页脚 = OTHER。

### M13 机构通告与鸣谢
- **核心问题**：文本规定了哪些规章/程序/权责边界？播报了哪些具体动态/近期活动？如何动员捐赠/致谢？如何缅怀已故人物？
- 包含：约束性入学/学位要求（"must", "are required to"）、学分最低要求、申请截止/合规程序、官方免责声明；具名的近期讲座/研讨会/工作坊与具名近期新闻（具体奖项、任命、出版）；捐赠呼吁（"Give Today", "Make a gift"）、礼物影响说明、捐赠渠道、具名捐赠者/捐赠基金致谢；讣告、"In Memoriam"、对已故个人的致敬。
- 边界：大学奖学金/助学金 = M07；慈善捐赠/捐赠者感谢 = M13；缅怀历史事件周年 ≠ M13；一般建系历史 = M02；"eligibility" 陷阱：推广奖学金/研讨班福利 = M07，而非 M13。

### OTHER 非简介话语残渣
- (a) 孤立的网页导航菜单、无动词的章节标题（"About Us", "Contact Us", "Faculty", "Our History"）、HTML/图片 alt 片段、乱码、采集者笔记；
- (b) 纯名录卡片（在读博士/硕士/本科生列表、学生 spotlight 卡片、分页名录）、跨子页面重复的侧边栏/页脚；
- (c) 完全非语言院系的跑题文本，或外部第三方组织以"we"自述的文本（如外部杂志）。

## 三、combined moves 规则

- 单句同时实现两个**对等、独立**的修辞 Move 时，保持整句完整，使用嵌套标签：`<MXX><MYY>...</MYY></MXX>`。
- **嵌套顺序规则**：外层 = 主导 Move（文本中信息量/篇幅更重者），内层 = 次要 Move；若难以判断，按 Move 编号升序（外层编号更小）。
- 仅当两个 Move 都具有独立的命题分量时才合并；从属修饰语（如"nine language programs"）不单独成 Move。

## 四、格式规范

1. 散文段落：**一句一行**，标签仅在完整句子的句首与句尾。
2. 多行结构块（地址块、签名块、重复菜单）：整块包裹在单个 `<TAG>...</TAG>` 中。
3. 保留原文 100% 单词、拼写、标点；不修正、不翻译、不摘要。
4. 仅输出 XML 标注文本，无解释、无 markdown 代码围栏。

## 五、LLM 标注建议（降低负担）

- 使用 **few-shot**：提供 6–8 篇已人工标注的 gold standard 文本（覆盖 combined moves、OTHER、边界陷阱）。
- **双模型 + 人工校对不一致项**（Yu et al., 2026）：两轮不同厂商模型标注，人工仅校对不一致句，报告 corrected accuracy 与 Cohen's κ。
- **分层提示**：先粗分 Domain（I–V），再细分类，减少单次认知负荷。
- **预处理**：先句子切分与清洗导航/页脚，再标注。
